# assets/

MuJoCo scene files and robot models live here: the tabletop scene XML (table,
drawer, plate, mug, water bottle, cutlery) and the two SO-101 arm models, plus
any meshes/textures they reference. Trained model weights go in `assets/models/`
which is gitignored — share weights via a link in the team chat, not via git.
Keep scene XML files in git so everyone runs the identical environment.
